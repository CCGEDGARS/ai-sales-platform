# Lepers Golden Master Implementation

Implemented controls:

- deterministic reference fingerprint derived from the approved Rihards Lepers production document;
- minimum Golden Master conformance threshold of 95/100;
- weighted scoring across structure, depth, VO amount, fifth-diner humour/POV, pace, production usefulness, promo, character insight and formatting;
- automatic background-response revision whenever the package misses format, VO-ratio or Golden Master threshold;
- measurable deficiency feedback passed into correction while preserving the user's Global Scene Directive and factual transcript constraints;
- hard rejection after the correction ceiling if a Lepers package still scores below 95/100;
- visible `Lepers Golden Master · locked 10/10 benchmark` mode label;
- visible returned Golden Master score and dimension breakdown;
- existing formatted final DOCX remains the final production export.

Production rule: variation is allowed in episode content, never in the locked production standard.
