# Browser & UI Verification
Source inspection is not sufficient evidence. Confirm target URL/environment, load the exact route, check visible errors, console and critical network calls, exercise changed interactions and loading/success/empty/error states, refresh for persistence, test desktop/mobile when relevant, and verify forms/auth paths. After deployment open the exact deployed URL and exercise the critical path. Report what was tested and anything not testable.
