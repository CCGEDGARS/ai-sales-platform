# CCGROUP Development Standard
Inspect before changing. Preserve working functionality, data, credentials, environment configuration, and integrations. Never fabricate results, expose secrets, weaken security/tests, or call a workaround finished when a root fix is feasible. Prefer branch/preview/staging for material work. Add tests for changed behavior. Verify desktop/mobile and browser console/network for UI work. Production promotion requires explicit approval. If verification cannot be performed, state exactly what remains unverified.
