# Spec-Driven Development
Inspect current implementation, tests, docs, schemas, and config. Define goal, current behavior, desired behavior, scope, acceptance criteria, affected files/APIs/data/auth/UI/migrations, risks, assumptions, and verification plan. Resolve ambiguity from repository evidence first. Implement against the contract and do not silently expand scope.
