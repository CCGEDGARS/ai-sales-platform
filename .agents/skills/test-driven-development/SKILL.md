# Test-Driven Development
Define one observable behavior; add or identify a test; confirm failure when feasible; make the smallest implementation change; run the focused test; refactor; run the broader relevant suite. For bugs reproduce first and add regression protection. Do not delete valid tests or weaken assertions merely to pass.
