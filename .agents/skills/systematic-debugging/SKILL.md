# Systematic Debugging
Do not guess-and-patch. Capture exact symptom and environment, reproduce, gather logs/stack traces/console/network/data/config/recent diffs, localize the failing layer, rank hypotheses, test the cheapest discriminating hypothesis, fix the root cause, add regression protection, rerun the original reproduction and adjacent flows. If a previous fix failed, stop stacking patches and reassess.
