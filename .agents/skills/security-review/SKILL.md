# Security Review
Review authentication, authorization, tenant/object boundaries, injection, XSS, SSRF, traversal, uploads, output encoding, redirects, secrets/logs/CORS, sensitive data, dependencies, webhooks, rate limits, database/cloud permissions as relevant. Trace untrusted input to sensitive sinks, confirm protections server-side, rank findings by evidence/impact, prefer minimal remediation, and add regression tests when practical. Never expose secrets or claim vulnerabilities without evidence.
