# Context Engineering
Relevant context beats maximum context. Load authority first: user instruction, AGENTS.md, repo docs, package/config files, schemas, nearby code, tests, deployment config. Track goal, constraints, architecture, key files, APIs, data model, environment, decisions, assumptions, and risks. Avoid unrelated/stale context. Re-read changed sources and preserve durable decisions in repository docs or project-specific skills.
